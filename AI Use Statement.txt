AI Usage Statement

For this project, I used Google Gemini AI browser functionality and ChatGPT as a support tool during the planning, documentation, and code review process. AI assistance was used to help clarify the project requirements, organize the documentation, improve wording, and provide guidance on GitHub usage and code comments.

The core project idea, implementation decisions, testing, and final code were completed by me. AI-generated suggestions were reviewed, edited, and validated before being included in the final project. ChatGPT was not used to replace my own work, but rather as a learning and productivity aid to help improve clarity, structure, and presentation quality. AI was used to help explain how pandas works, including concepts such as DataFrames, `groupby()`, `agg()`, `unique()`, `nunique()`, and exporting data to Excel.

I also used AI to help explain programming concepts and troubleshoot general workflow steps, such as preparing the repository and organizing project files for submission. All final content and code were reviewed to ensure they accurately reflect my understanding and the tool's functionality.
